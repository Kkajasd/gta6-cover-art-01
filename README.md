Vice Panel Press — an offline web app that turns any photo into multi-panel GTA-style cover art: bold caption lettering, a Vice City sunset/neon colour grade, six poster layouts, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Photos are read on your own machine and never uploaded.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — add a photo, pick a layout and grade, drag a panel to reposition its photo, and hit Export PNG.
